先看全流程

五步就能开始训练

首次设置耗时主要在 PC 工具下载环境和模型。完成一次后，后续添加歌曲只需分析、复制和重新扫描。

  1. 01安装工具在 PC 上完成一次初始化
  2. 02分析音乐为每首歌生成同名 JSON
  3. 03整理课程一个课程对应一个文件夹
  4. 04USB 复制复制到 Quest 内部存储

最重要的规则

每首音频必须和一个 基础文件名完全相同的 JSON 放在同一课程文件夹中。例如 Song A.ogg 对应 Song A.json。

开始之前

准备这些设备和空间

✓
一台兼容电脑

Windows x64，或 Apple Silicon（M 系列）Mac。

✓
支持数据传输的 USB 线

仅能充电的线无法在电脑中显示 Quest 存储。

✓
足够的电脑磁盘空间

CPU/Mac 建议至少 6 GB，NVIDIA CUDA 建议至少 12 GB。

✓
Quest 可用空间

需要容纳原始音频，以及游戏首次扫描后生成的本地缓存。

隐私说明

PC 工具在你的电脑上读取和分析音频，Gradio 页面运行于 127.0.0.1。音乐不会因为使用该页面而上传到远程服务器。

1
PC 端

下载并初始化分析工具

1.1 获取项目

  1. 打开 AllInOneInferPortable 项目页。
  2. 点击 Code → Download ZIP，下载后将压缩包完整解压到本机磁盘。
  3. 不要在压缩包预览窗口中直接运行脚本；初始化前先确定最终存放位置。

1.2 Windows 首次初始化

  1. 双击 platforms\windows\init.bat。
  2. Windows 请求管理员权限时选择“是”。
  3. 如果检测到 NVIDIA 显卡，按需求选择 CUDA 版；不确定时可以选择 CPU 版。
  4. 保持窗口开启，直到看到 Setup complete。
下载时间较长是正常的

CPU 版通常下载约 1.5～2.5 GB，CUDA 版约 3～5 GB。首次分析还可能继续下载模型。

1.2 macOS 首次初始化

仅支持 Apple Silicon（M 系列）Mac。在项目目录打开终端，执行：

chmod +x platforms/macos/init.command platforms/macos/start.command
./platforms/macos/init.command

如果 Gatekeeper 阻止运行，可在 Finder 中右键 init.command，选择“打开”并确认一次。等待出现 Setup complete。

2
PC 端

分析音乐并生成 JSON

2.1 启动本地页面

Windowsplatforms\windows\start.bat
macOSplatforms/macos/start.command

浏览器通常会自动打开 http://127.0.0.1:7860。没有自动打开时可手动输入。关闭启动器窗口会停止本地服务。

2.2 选择分析方式

单首歌曲

Single File

  1. 点击 Browse... 选择音频
  2. 点击 Start Analysis
  3. 等待状态显示完成
多首歌曲

Directory

  1. 点击 Browse... 选择目录
  2. 选择是否递归子目录
  3. 点击 Start Directory Analysis
PC 工具支持的格式不等于游戏支持的格式

分析工具可读取 WAV / FLAC / MP3 / OGG / M4A / AAC / WMA，但当前 Quest 游戏只导入 MP3、WAV、OGG。如果原曲是其他格式，请先转换为这三种格式之一，再分析转换后的最终文件。

2.3 找到生成结果

每次任务会在以下位置创建一个带时间戳的结果目录：

AllInOneInferPortable/
└─ outputs/
   └─ gradio/
      └─ <运行时间戳>/
         ├─ Song A.json
         └─ Song B.json

运行日志位于 Portable/logs/。如果分析失败，保留对应日志有助于排查。

便携版无法完成分析？

可以改用上游的 openmirlab/all-in-one-infer 工程分析音乐并生成节拍数据。环境安装、音乐分析和结果导出方法，请按照该项目的 README 文档操作。

3
PC 端

整理课程目录

在 PC 上新建一个根目录，建议命名为 FistStrikeSongs。根目录中的每个一级子文件夹就是一个课程。

FistStrikeSongs/                 ← 游戏中选择这个根目录
├─ 周末燃脂/                    ← 课程 1
│  ├─ 01 - Artist A - Song A.ogg
│  ├─ 01 - Artist A - Song A.json
│  ├─ 02 - Artist B - Song B.mp3
│  └─ 02 - Artist B - Song B.json
└─ 慢速热身/                    ← 课程 2
   ├─ 01 - Artist C - Song C.wav
   └─ 01 - Artist C - Song C.json
一个课程一个文件夹

只扫描根目录下的一级子文件夹，不要再嵌套歌曲目录。

音频和 JSON 同名

扩展名之前的文件名必须相同，大小写也建议保持一致。

歌曲放在课程文件夹内

直接放在 FistStrikeSongs 根目录的歌曲不会被导入。

使用编号控制顺序

歌曲按文件名排序，可添加 01 -、02 - 前缀。

正确Morning Run.oggMorning Run.json
错误Morning Run.oggMorning_Run.json
避免同基础文件名冲突

同一课程里不要同时放置 Song.mp3 和 Song.ogg。它们会被视为重名音频，均无法导入。

4
PC → Quest

通过 USB 复制课程

  1. 使用支持数据传输的 USB 线连接 Quest 与电脑，并保持 Quest 解锁。
  2. 如果头显中出现文件访问提示，选择“允许”。
  3. 在电脑文件管理器中打开 Quest 内部共享存储。
  4. 进入 Documents/FistStrikeVR/；目录不存在时可手动创建。
  5. 将整个 FistStrikeSongs 文件夹复制进去，等待传输完成后再断开 USB。
Quest 内部存储/
└─ Documents/
   └─ FistStrikeVR/
      └─ FistStrikeSongs/
         ├─ 周末燃脂/
         │  ├─ 01 - Artist A - Song A.ogg
         │  └─ 01 - Artist A - Song A.json
         └─ 慢速热身/
            ├─ 01 - Artist C - Song C.wav
            └─ 01 - Artist C - Song C.json
5
Quest 游戏内

选择目录并开始训练

  1. 启动 Fist Strike VR，进入“自定义课程”。
  2. 点击右上方“选择目录”。
  3. 在系统目录选择器中进入 Documents/FistStrikeVR/FistStrikeSongs。
  4. 停留在 FistStrikeSongs 根目录，点击“使用此文件夹”并允许访问。不要进入某个单独课程后再确认。
  5. 返回游戏等待扫描完成。出现课程卡片后，点击课程即可进入训练。
首次扫描为什么较慢？

游戏会读取分析 JSON，并将可用歌曲复制到应用缓存。后续未改动的歌曲会复用缓存；扫描过程中请不要退出游戏。

后续维护

增加、替换或移除歌曲

  1. 在 PC 上分析新歌曲，得到同名 JSON。
  2. 按相同规则放入已有课程，或新建一个一级课程文件夹。
  3. 通过 USB 将变化复制到 Quest，确认覆盖或删除对应文件。
  4. 回到“自定义课程”页面，点击“重新扫描”。

如果更换了整个根目录，使用“选择目录”重新授权。只修改已有目录内容时，不需要再次选择目录。

问题处理

常见问题与解决方法

电脑中看不到 Quest 存储

确认 USB 线支持数据传输；保持头显解锁；在头显内允许文件访问。仍不可见时更换 USB 端口或数据线后重新连接。

游戏中一个课程都没有

确认选择的是 FistStrikeSongs 根目录，其下至少有一个一级课程文件夹；歌曲不能直接放在根目录，也不会递归扫描更深层目录。

提示缺少同名分析文件

检查音频与 JSON 是否位于同一课程文件夹，并确保扩展名之前完全同名。例如 Song.mp3 必须对应 Song.json。

提示音频格式不支持

Quest 端当前只支持 MP3、WAV 和 OGG。请在 PC 上转换格式，并针对转换后的最终音频重新生成 JSON。

分析 JSON 无效或歌曲无法使用

删除旧 JSON，使用最新 PC 工具重新分析对应音频。不要手动改写 JSON 内容。若音频曾被替换，也应重新生成 JSON。

同一课程出现文件名冲突

不要让两个不同格式的音频使用相同基础文件名。分别重命名音频，并重新生成与新名称匹配的 JSON。

扫描或缓存失败

检查 Quest 可用空间，确保复制已完成，再重新扫描。必要时缩小单次课程规模并重试。

分析页面显示“Analysis failed (exit code 1)”或 WinError 5

如果出现如下图所示的报错，请先关闭 PC 分析工具，删除工具目录中的 Portable/models 文件夹，然后重新启动工具并再次分析。模型文件会重新下载，请保持网络连接并等待下载完成。

PC 工具初始化或启动失败

重新运行当前平台的初始化脚本，检查网络、磁盘空间和 Portable/logs/。Windows 的 WinError 5 请检查 UAC、Windows 安全中心和杀毒软件；macOS 权限问题可重新执行 chmod +x platforms/macos/*.command。

MP3 在 PC 工具中解码失败

安装 FFmpeg，或将音频转换为 WAV/OGG 后重新分析。不要从非官方网站单独下载 DLL。
