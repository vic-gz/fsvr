自定义课程

喜欢的音乐，
也能成为训练课程。

在电脑上为本地音乐生成节拍分析文件，整理成课程后通过 USB 复制到 Quest。游戏扫描目录后即可开始训练。

  • 1PC 分析音乐生成与音频同名的 JSON
  • 2USB 复制课程支持 MP3、WAV、OGG
