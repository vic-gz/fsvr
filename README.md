# fsvr

Fist Strike VR website.

## GitHub Pages

发布目录为 `web/`：

- 项目主页：`web/index.html`
- 自定义课程教程：`web/diy/`

English is the default language. Chinese pages are available at:

- 项目主页中文版：`web/zh/`
- 自定义课程教程中文版：`web/diy/zh/`

<https://vic-gz.github.io/fsvr/diy/>

本地预览：

```powershell
python -m http.server 8000 --directory web
```

然后访问 <http://127.0.0.1:8000/diy/>。
